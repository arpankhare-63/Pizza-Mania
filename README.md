# 🍕 Pizza Mania Sales Analysis (SQL)

## Overview

Pizza Mania Sales Analysis is a SQL-based data analytics project that explores pizza sales data to uncover business insights. The project focuses on analyzing customer orders, revenue trends, product performance, and sales patterns using SQL queries.

## Objectives

* Analyze overall sales performance.
* Identify top-selling pizzas and categories.
* Track revenue trends and peak order hours.
* Understand customer ordering patterns.
* Generate actionable business insights.

## Tools & Technologies

* SQL
* MySQL

## SQL Concepts Used

* SELECT, WHERE, ORDER BY
* GROUP BY & HAVING
* Aggregate Functions
* JOINS
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions

## Key Insights

* Identified the highest revenue-generating pizzas.
* Analyzed category-wise sales performance.
* Determined peak ordering hours and busiest days.
* Calculated total revenue and average order value.
* Evaluated cumulative revenue trends.

## Dataset

The dataset contains information about pizza orders, order details, pizza types, sizes, quantities, prices, and order timestamps.
